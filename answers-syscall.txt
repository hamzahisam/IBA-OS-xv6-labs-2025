Q4: Write down the assembly instruction the kernel is panicking at when num = *(int*)0; is inserted. Which register corresponds to the variable num?
Ans: This was the Panic info:
        sepc = 0x80001d14
        scause = 0xd
        stval = 0x0
        
        Looking at kernel/kernel.asm:
        lw a3,0(zero)    # load word from address 0
        
        So it crashedon NULL derefrence and the variable num corresponds to a3
        
Q5: Why does the kernel crash?
Ans: Because the kernel tries to load from address 0, which is not mapped in the kernel address space
